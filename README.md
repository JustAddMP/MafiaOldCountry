# Mafia: The Old Country — Co-op

**Status: planned.** Work hasn't started yet.

This will be a co-op mod for Mafia: The Old Country, built on the shared
[JustAddMP core](https://github.com/JustAddMP/core) framework. The Old Country runs on Unreal Engine 5, unlike the
earlier Mafia games, so the networking, launcher and Steam parts carry over from core while the game layer is new.

Follow progress on [justaddmp.com](https://justaddmp.com).
